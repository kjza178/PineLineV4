# run_v2.bat báo không thấy Python / lệnh n,t,exist,not

- **Date:** 2026-11-10
- **Job / khu vực:** launcher `run_v2.bat` (V2)
- **Status:** fixed

## Triệu chứng

Chạy v2/run_v2.bat: `'n'/'t'/'exist'/'not' is not recognized` rồi `[loi] Khong thay C:\Python312\python.exe` dù Python 3.12 có trên máy.

## Root cause

`Z:\PinelineV2\run_v2.bat` (và `run.bat`, `run_tele_cmd.bat`) lưu **LF-only** (Unix). CMD Windows parse hỏng các dòng `if not exist` / `if not defined` → biến `PY` không bao giờ được gán.

## Evidence

- `CRLF=0 LF_alone=46` trên `run_v2.bat` trước fix
- `Test-Path C:\Python312\python.exe` = True

## Fix

- Chuyển CRLF 3 file launcher; backup `Z:\PinelineV2_codebak\2026-11-10_run-v2-crlf\`
- Escape ngoặc trong dòng echo UI

3. **Fail nếu:** vẫn `Khong thay C:\Python312\python.exe` hoặc `'exist' is not recognized`
